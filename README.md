# Focus Timer & To-do

A lightweight focus timer and task list that runs directly in your browser. The app is a single HTML file and does not need a server, build step, or external dependencies.

## Features

- 25-minute focus timer with start, pause, and reset controls.
- 5-minute break mode.
- A beep when a focus or break timer finishes.
- Daily count of completed focus sessions, saved in local storage.
- To-do list with add, complete, and delete actions. Tasks are saved in local storage and remain after refreshing the page.
- Responsive dark layout designed for desktop and mobile screens.

## Run the app

1. Open the project folder in your file browser.
2. Double-click `index.html`, or right-click it and choose your browser.
3. Choose Focus or Break, then press **Start**. Add tasks in the to-do section below.

No installation or internet connection is required. Your to-dos and daily session count are stored in the browser on the device where you use the app.
